# 介绍网站建设计划（展示站 · 视频介绍用）

> 来源：2026-08-25 会话。为 Ariadne 项目建设一个**视频介绍用展示网站**：完整呈现系统架构（不含论文实验数据），采用上下滚动叙事揭幕式交互，暗色科技风，3D 力导向图为核心视觉。
>
> 用途定位：本地 `dev server` 录制视频介绍（非公开运营站，不做 SSR/SEO）。技术决策已与用户逐项确认（见 §2）。
>
> **版本管理约束**：本计划所有产物（`website/` 目录、`bake_graph.py` 脚本、`graph.json` 数据）**不参与 git 追踪**，已加入 `.gitignore`（2026-08-25）。网站为本地视频介绍用临时产物，不入仓库。

---

## 一、目标与原则

1. **内容**：覆盖系统完整架构（抽取 → 存储 → 检索 → 故事 → 接入五层链路），**不出现**实验数据/评测数字/对比表格（论文内容不在本展示站范围）。
2. **交互**：上下滚动切换章节，采用**滚动叙事揭幕式**（内容随滚动进度逐帧/视差/渐进展开），动效流畅可用于视频录制。
3. **视觉**：暗色科技风——深色底 + 图谱光点/连线 + 紫/青霓虹强调色，契合「记忆迷宫之线」主题。
4. **3D**：基于现有 Three.js 力导向图技术**重建适配版**，用 LiFEMem 真实数据**预烘焙静态坐标**，录屏不依赖 Python 服务。
5. **语言**：中英混排（中文为主，关键术语标注英文：DBA / StoryRank / Jump Axis 等）。

## 二、技术选型（已确认）

| 维度 | 选择 | 理由 |
|------|------|------|
| 工具链 | **Vite + React (TS)** | dev server 秒启、HMR 快、产物静态可部署；视频录制场景不须 SSR |
| 滚动动画 | **Lenis + GSAP ScrollTrigger** | 获奖站滚动叙事主流组合；Lenis 惯性滚动 + ScrollTrigger pin/scrub 逐帧控制「揭幕」 |
| 3D | **three + 3d-force-graph**（React 封装） | 复用现有面板已验证技术（dashboard_3d.html 同栈），数据预烘焙后仅静态渲染 |
| 样式 | **TailwindCSS v4（CSS-first）+ CSS 变量** | v4 用 `@tailwindcss/vite` 插件 + CSS `@import "tailwindcss"` 配置（无需 tailwind.config.ts）；暗色主题与统一动效 token |
| 字体 | 标题可变字体 + 系统中文栈 | 中英混排：标题英文用 Space Grotesk，正文中文系统栈（思源/苹方/微软雅黑） |
| 图标 | lucide-react | 轻量、线性风格契合科技感 |
| 数据 | `website/src/data/graph.json`（预烘焙） | 由 Python 脚本从 `data/LiFEMem.yaml` 导出轻量静态图数据 |

## 三、内容结构（章节规划）

**不含实验数据**，章节按系统链路组织（每章 = 一个滚动揭幕场景）：

| # | 章节 | 内容 | 动效要点 |
|---|------|------|---------|
| 1 | **Hero** | 项目名 Ariadne + 副标题「记忆迷宫之线 / A thread through the labyrinth of memory」+ 一句定位 | 3D 图谱全屏背景，标题逐字入场 |
| 2 | **问题与理念** | Agent 如何管理记忆？语义记忆 vs 情景记忆的**分离与合作**（两卡片对照） | 双卡片视差进入 + 关键词强调 |
| 3 | **核心链路总览** | 对话日志 → DBA 维护 → MemoryGraph+VectorStore → P 检索 → StoryRank → 回复 | 横向流程逐步揭幕（scroll scrub 连线动画） |
| 4 | **抽取层 · DBA** | 两步抽取（节点/边）、纠错、废弃（deprecate）、批量异步调度 | 节点从日志中"析出"动画 |
| 5 | **存储层 · 图谱+向量** | 6 种节点角色 × 8 种关系类型、边方向与权重、向量索引 | 图谱局部放大 / 高亮聚焦 |
| 6 | **检索层 · P 链路** | 跳转轴（Jump Axis）/ 目的回归（Purpose Regression）/ 寻峰终止（Peak Finding）三机制 | 三机制依次高亮 + 路径动画 |
| 7 | **故事层 · StoryRank** | 因果链路 → 故事片段；避免污染聊天上下文 | 列表 → 故事文本渐变动画 |
| 8 | **接入层** | API Server / MCP Server（6 tools）/ 3D 可视化 / 离线 HTML 四种形态 | 四卡片依次入场 |
| 9 | **3D 演示区** | LiFEMem 真实图谱交互（旋转 / 聚焦 / 类型过滤），静态预烘焙 | 图谱自转 + 点击聚焦 |
| 10 | **结尾** | 未来方向（知识库/经历库分层）+ GitHub / 文档链接 | 渐隐 + CTA |

> 内容素材来源：README.md（架构图、核心特性、分层表、MCP 详解）、理论部分文档的**非实验**章节（问题定义、语义/情景记忆分离、检索三机制原理）、`data/LiFEMem.yaml`（图谱数据）。

## 四、3D 力导向图方案（重建适配版）

- **预烘焙**：新增 Python 脚本 `website/scripts/bake_graph.py`，读 `data/LiFEMem.yaml` → 输出 `website/src/data/graph.json`（节点 id/content/type + 边 from/to/type，坐标由 3d-force-graph 首次布局后固定保存，避免实时力模拟的性能抖动）。
- **渲染**：React 组件 `ForceGraphCanvas` 封装 three + 3d-force-graph，挂载在 Hero 全屏背景与 §9 演示区；节点按类型着色（STATUS/REASON/ACTION/THING/PERSON/EMOTION 六色系）、连线按关系类型透明度分级。
- **与滚动联动**：Hero 图谱随滚动缓慢旋转/缩放（ScrollTrigger scrub）；§9 支持鼠标轨道旋转 + 聚焦高亮 + 类型过滤按钮。
- **性能/降级**：固定相机距离、限制粒子数量；`prefers-reduced-motion` 或 GPU 受限时降级为静态图谱 + 纯 CSS 渐变背景。

## 六、交互与动效规范（视频录制友好）

- **章节节奏**：每章 ≈100vh（或整数倍），单章动效完成时间 1.5–2s，滚动阻尼适中（Lenis `duration≈1.1`），避免录制时晕动/卡顿。
- **统一动效 token**：入场 = opacity 0→1 + y 18px→0，缓动 `power3.out`；强调 = scale 1→1.04 + 霓虹 glow；全站同一套 ease/duration（GSAP 配置集中一处）。
- **进度导航**：右侧章节圆点导航（点击 ScrollTo 跳转），顶部章节标题随滚动更新——录屏时可演示任意章节。
- **降级策略**：`prefers-reduced-motion` 时停用 scrub/视差，仅保留淡入；3D 失败时静态降级。

## 七、实施步骤（P0/P1/P2）

**P0 · 骨架与核心动效**
1. Vite + React + TS + Tailwind 脚手架（`website/` 目录）；
2. Lenis + ScrollTrigger 接入（`useSmoothScroll`），验证惯性滚动与 scrub 联动；
3. `bake_graph.py` 预烘焙 LiFEMem 数据 → graph.json；
4. ForceGraphCanvas 组件（Hero 背景）跑通；
5. 10 个章节组件 + 内容文案填充；
6. 核心链路（§3）流程揭幕动画、检索层（§6）三机制路径动画。

**P1 · 打磨与演示增强**
7. 章节入场/视差全量配置（统一 token）；
8. 3D 演示区（§9）交互（聚焦/过滤/旋转）；
9. 进度导航 + 章节标题联动；
10. 中英混排文案校对、术语表。

**P2 · 稳定与收尾**
11. reduced-motion / 3D 降级路径验证；
12. 全站动效性能检查（滚动流畅度、无布局抖动）；
13. 本地录屏演示走查（`npm run dev` 全章节过一遍）；
14. 可选：`npm run build` 静态产物与部署说明。

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| 322 节点力导向图录屏时 GPU 压力 | 预烘焙固定坐标（不做实时力模拟）+ 相机距离固定 + 降级静态图 |
| Lenis 与 ScrollTrigger 不同步（滚动错位） | `lenis.on('scroll', ScrollTrigger.update)` 标准联动模式 + 初始化后 `ScrollTrigger.refresh()` |
| 滚动叙事在录屏中节奏不稳 | 统一动效 token、每章 1.5–2s 完成、录制前全章节走查 |
| React StrictMode 双挂载导致 3D/GSAP 重复初始化 | 3D 与 Lenis 均在 `useEffect` 内初始化并清理，StrictMode 下幂等 |

## 九、交付物

- `website/` 完整可运行项目（`npm install && npm run dev` 即用）；
- `scripts/bake_graph.py` 数据预烘焙脚本；
- 本计划作为实施依据（P0 完成后按需更新）。
