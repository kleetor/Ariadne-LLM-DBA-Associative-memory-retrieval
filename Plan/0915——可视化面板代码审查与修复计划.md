# 0915 —— 可视化面板代码审查与修复计划

审查范围：`dba_pipeline/viz/`，共 15 个文件（后端 5 + 前端 JS/CSS/HTML 10），约 5,700 行。
审查方式：逐文件通读 + 真实浏览器实测（`127.0.0.1:8801`）复核关键结论。
状态：**已执行完毕**，执行结果见文末第五节。

---

## 一、审查结论摘要

主要问题集中在三类：

1. **安全**：登录页存在可实测复现的开放重定向；全站无安全响应头；500 响应回传内部异常细节；两处 innerHTML 插值未转义。
2. **数据完整性**：图谱写盘失败被静默吞掉仍返回成功；前端 `DEFAULT_SETTINGS` 被别名污染；数据重载后聚焦状态残留导致图谱大面积消失。
3. **一致性/健壮性**：同一份「选中态」存三处靠人工同步；轮询重载会丢用户固定节点且存在竞态；CDN 失败会让整个面板静默失效。

后端 `webauth.py`、`logbus.py` 的跨进程/并发设计质量明显高于其余部分（PBKDF2+pepper、mtime 门控重载、原子替换、SSE 心跳、写路径跨进程 FileLock），本次未改动其核心逻辑。

## 二、修复清单

### P0 — 安全与数据完整性

- [x] **P0-1 登录页开放重定向**（`static/login.html`）
  `nextTarget()` 改为 `new URL(raw, location.origin)` 解析后比对 `origin`，不一致回退 `/`。

- [x] **P0-2 数据重载后聚焦状态残留 → 图谱大面积消失**（`static/js/graph.js`）
  `setData()` 一并清空 `focusId / focusSet / hoverId`。

- [x] **P0-3 `DEFAULT_SETTINGS` 被别名污染**（`static/js/store.js`）
  新增 `clone()`，初始加载、`reset()` 与 `A.const.DEFAULT_SETTINGS` 导出处均改为深拷贝。

- [x] **P0-4 落盘失败被吞掉仍返回成功**（`api_server.py`）
  `_save()` 不再吞异常，失败时把 `_last_mtime` 置为 `-1`（下一次读操作强制以磁盘为准并丢弃未持久化的内存改动）后上抛，由 `on_error` 转 500。

### P1 — 功能与视觉缺陷

- [x] **P1-5 搜索选中绕过 `onSelect`**：`graph.js` 的 `select()` 成为选中态唯一出口并触发 `hooks.onSelect`；删除 `handleNodeClick` / `handleBackgroundClick` / `app.js` / `panels.js` 各调用点的手工同步，并移除重复的 `onBackgroundClick` hook。
- [x] **P1-6 右键菜单定位**：先 `classList.add('open')` 再测 `offsetWidth/offsetHeight`，并用实测宽高做双向钳位（去掉硬编码的 220）。
- [x] **P1-7 相机悬浮窗压住检查器**（`css/app.css`）：`#panel-inspector` 加 `max-height: calc(100% - 220px)`，为相机区预留高度。
- [x] **P1-8 CDN 失败导致面板静默失效**（`app.js`）：特性检测 + `try/catch`，失败时在舞台内渲染 `.graph-error` 提示，并**继续**初始化面板；`graphReady` 门控阻断对未初始化图谱的操作。
- [x] **P1-9 XSS 纵深防护**：`util.js` 的 `fmtTime` 兜底分支改为 `escapeHtml`；`panels.js` 的 `level` 走 `LEVEL_CLASSES` 白名单后才进 class 属性位。
- [x] **P1-10 轮询重载丢固定节点 / 降级聚焦 / 竞态**：`setData` 按 id 还原钉住位置与钉圈；`state.focusHops` 记录跳数并导出 `getFocusHops()`，重载时按用户跳数还原；`app.js` 加重载序号，只应用最后一次结果。
- [x] **P1-11 安全响应头 + 500 信息泄露**：新增 `SecurityHeadersMiddleware`（`X-Frame-Options: DENY`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: same-origin`）；500 改为固定文案，细节只进服务端日志。
- [x] **P1-12 前端 fetch 无超时**（`api.js`）：`request()` 默认 30s 超时（`AbortSignal.timeout`，缺失时 `AbortController` 兜底）；`getHealth` 同样加超时；调用测试用 `timeout: 0` 关闭（其完成信号走 SSE）。
- [x] **P1-13 MCP 徽章 `pill-btn` 类被打飞**：`renderMcpPill` 改为 `classList` 增删状态类；`#mcp-pill` 由 `<span>` 改为 `<button>`；补 `.pill.ok/.warn.pill-btn:hover` 以免 hover 盖掉状态色。
- [x] **P1-14 `ChainRunner` 装配失败重复付代价**（`chain_runner.py`）：缓存装配错误、不再重试；删除无消费者的 `ready` 接口（`init_error` 保留，供诊断）。

## 五、执行结果（2026-09-15）

**语法检查**：6 个 JS 与 3 个 Python 文件全部通过。

**浏览器实测确认**：

| 验证项 | 结果 |
| --- | --- |
| 安全响应头 | `/login` 返回 `x-frame-options: DENY`、`x-content-type-options: nosniff`、`referrer-policy: same-origin` |
| P0-1 开放重定向 | `raw = /\evil.com` → 解析为 `http://evil.com/`，`sameOrigin === false` ⇒ 守卫回退 `/`（原实现判为站内、会跳外站） |
| P0-3 默认值污染 | `reset()` 后执行 `update('render','nodeScale',0.5)`，`A.const.DEFAULT_SETTINGS.render.nodeScale` 仍为 `1.6`（修复前会变成 0.5） |
| P1-6 右键菜单 | 菜单隐藏时 `display:none / offsetHeight=0`（实测），已改为先展开再测量 |
| P1-7 面板遮挡 | `#panel-inspector` 计算值 `calc(100% - 220px)`；stage 高 409px、相机面板占 274–445px，原实现最长可到 449px 而重叠 |
| P1-13 MCP 徽章 | `tagName=BUTTON`、`className="pill pill-btn ok"`、`cursor:pointer`（修复前只剩 `pill ok`） |
| P1-21 键盘可达 | 搜索「加班」得 6 条结果，逐项 `tabindex="0"`；打开设置抽屉后按 Esc 成功关闭（`data-tab` 回到 `graph`） |
| 整体健康 | 面板 `MCP 在线 · 12ms`、`服务正常`、223 节点、无 `.graph-error`；`/api/metrics` 显示 SSE 订阅者 1 |

**仅经代码路径确认、未做浏览器端行为复现的项**：

- **P0-2**（重载后聚焦残留）：3d-force-graph 实例未挂到 DOM 上（实测容器无任何 `__*` 属性），而 `#stat-nodes` 取自 `visibleSets()`、不反映聚焦可见性，因此无法从页面侧观测。改动本身是 `setData()` 里 3 行显式重置，且 `applyVisibility()` 以 `focusId` 为开关已逐行确认。
- **P0-1 的端到端跳转**：需要真实登录凭据，未在浏览器里走完「登录成功 → 按 `next` 跳转」这一步；守卫分支已按上述方式确认。
- **P2-19 / P2-20 / 各处死代码删除**：静态改动，无独立运行时行为可观测。

**遗留风险**：`api_server.py` 的 `_save()` 现在会把写盘失败上抛为 500。若磁盘满或 YAML 目录不可写，原先「静默成功」的 CRUD 操作会开始**报错**——这是预期行为（宁可报错也不要静默丢数据），但初次遇到时可能被误认为是新 bug。
