### 10-12 ~ 10-13 · 稳定性改造、重排接入与开源整理

- **出站配额节流**：按**字符速率**的令牌桶（等待式 + AIMD 自适应），覆盖 embedding / LLM / rerank 三条出网链路。
- **检索稳定性四措施**：TopK 压制、建图等待窗、回补独立批次、回补进度按原始消息计数。
- **Cross-encoder 重排接入**：仅作用于纯向量通道，失败**静默降级**回余弦序。
- **上游配额实测与标定**：实测 rerank 的上游限速口径与「字符 → token」折算比，据此标定节流上限。
- **运维与开源整理**：容器内存稳态（LRU 换出 / 重载，不重新嵌入）确认；注释与文档面向开源清理；内部规划与实验报告移出仓库。
